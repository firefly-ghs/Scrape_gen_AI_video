常见问题

生成一段视频会消耗多少积分？

提交任务后页面会立即展示「预计消耗」；使用本地模拟引擎不消耗 token。真实额度余额以任务明细卡展示为准。

大概多久能生成完？

本地模拟引擎通常几秒内完成；火山 API 视排队与所选时长而定，页面会持续刷新任务进度，无需停留在本页。

生成失败了怎么办？

结果区会显示失败原因；你可以到「最近任务」里对失败任务点「复用提示词」，修改后重试。

上传的参考视频会被怎么处理？

参考视频仅用于本次生成任务，保存在本服务端任务目录中；请勿上传涉密或违规内容。
