​AI视频，「Runway」逆袭？

白鲸出海·2026年10月29日 10:20
模型掉队，ARR 翻倍。

打开如今的视频生成模型能力榜单，排名前列的模型均来自谷歌、字节、快手等等大厂。三年前，AI 视频赛道绕不开的「Runway」已经不在第一梯队。

Artificial Analysis 榜单，Runway 的最新模型 Gen4.5 已排不进前 10｜图片来源：Artificial Analysis

去年 12 月，Gen-4.5 短暂登顶 Artificial Analysis，但排名迅速滑落、被其他大厂的模型赶超，此后大半年，再没有推出新模型。

但形成对比的是，「Runway」的生意盘子却在悄悄变大。9 月初，联合创始人兼 CEO Anastasis Germanidis 在领英上公布了一组数据， ARR 已接近 2 亿美元，相比 4 月份的 1 亿美元，半年几乎翻倍。AppMagic 的数据也印证了这一趋势，仅移动端月流水就从去年 9 月的不到百万美元涨到了近 30 天 270 万美元，差不多能挤进全球 Top3。

Runway 流水趋势｜图片来源：AppMagic

模型掉队，产品突围

我们翻了一下「Runway」近半年的增长数据，发现有两个明显的拐点。

第一个在 5 月。AppMagic 显示，「Runway」的下载量和收入在这个月同步拉升，对应的是一款名为 Aleph 2.0 的模型上线，但它做的不是从零生成视频，而是“改视频”。

「Runway」下载、收入、RPD，红线 Download、蓝线 Revenue、黄线 RPD｜图片来源：AppMagic

根据官网的介绍，Alpph 2.0 的核心能力是理解已有视频的画面内容，按用户指令修改指定元素，同时保持其他画面、动作和场景不变；用户还可以先编辑单帧画面，再应用到整个视频，也支持在多个镜头内同步修改/替换主体或背景。

广告素材数量｜图片来源：广大大

结合广大大给出的投放数据来看，5 月份 Runway 的素材数量不到 50 个，远低于近期的投放水平，但同期，X 上出现了大量博主测评 Aleph 2.0 的视频。新模型刚上线的时间点上，Runway 采用的是“社媒推广为核心，配合小规模广告投放”的策略，执行该策略后，5月达到下载量峰值后，6、7月出现波动。｜图片来源：X

「Runway」围绕这个能力打造了一个极易传播的宣传点，“一句话改视频”，上传一条完整视频，输入“在肩膀上加个熊猫”，画面里就多了一只熊猫，其余一切不变。5 月，X 上大量博主自发测评 Aleph 2.0 带来了第一波下载，8 月底广告投放放大后又推动了第二波增长，两波策略不同，但核心卖点是同一个，改视频。

虽然从生成变成修改，但 Aleph 2.0 依然是 Runway 自研；但在整体的核心设计上，Runway 早就和其他做模型聚合的产品一样，不再专一（ps：目前，只有可灵几个最头部的产品仍只提供自有模型）。

我们体验了当前版本的 App 后发现，产品形态已经发生了根本性的变化。对比 2025年底的版本截图，自研模型 Gen-4 是门面，而如今 App 中默认的视频模型换成了 Seedance 2.0，生图模型换成了「GPT Image 2」。模型选择界面聚合了市面上主流的生成模型，Gen-4.5 仍可手动切回，但已不是默认选项。

Agent 模式页面（图1）、模型选择（图2）、功能选择（图3）、面向垂类需求的 Apps（图4），Apps 包括广告生成、一句话生成多镜头视频、先定分镜再出片、无需重拍去除画面物体、让角色依照真人表演的动作控制，以及口播视频等等。

此前的「Runway」主推 90 年代写真、AI 美发、风格滤镜等面向普通用户的玩法，改版后的产品更像一个以 Agent 为核心的创作工具——Agent 是对话式生成模式，Tool 是传统的提示词模式，面向广告生成、分镜出片、动作控制、口播视频等垂类场景的 Apps 构成了第三个板块。

在我们持续跟踪的 AI 视频产品中，能跑出收入（赚钱有很多种解释，利润为正是最根本的，和有收入是两码事情，严谨一些）的大致走了两条路径。

一条面向普通用户，以模板驱动，靠“单点功能+社媒引爆”带来下载和收入，年初的“宠物、婴儿舞蹈”，5月的“棒球现场特效”都是这条路上的爆款。另一条面向专业创作者和做广告营销的小 B 用户，靠模型聚合+Agent 提供一站式创作能力，代表产品有 ARR 已达 10 亿美元的 Higgsfield，OpenArt、Pollo.ai 等，ARR 也在千万美元以上。

「Runway」从前一条路整体切到了后一条。自研的 Aleph 2.0 从视频编辑切入市场，再用“模型聚合+Agent”接住用户的其他创作需求。模型在榜单上排不到前列，但产品端的转型换来了实打实的流水增长。

只是，按 8月约 180 万美元的移动端月流水折算，App 贡献的收入大概只占总量的一成。ARR 接近 2 亿美元的大头，在企业侧。

一套架构、三层生意，悄悄做到 2 亿美元

图片来源：LinkedIn

9 月初，「Runway」联合创始人兼 CEO Anastasis Germanidis 在领英上公开数据，「Runway」服务超 6000 万创作者，95% 的财富 100 强企业也是其客户。从官网及公开信息来看，企业侧收入来自两层生意，加上 C 端创作工具，总计有三层，面向不同客户，交付方式完全不同。

第一层是创作工具，也就是App 和 Web 端，面向创作者和小商家，核心商业模式是“订阅+积分”，是「Runway」最直接面向用户的入口，不再赘述。

第二层是 API，核心产品是「Runway Dev」，面向的是不需要专属模型的开发者，与其他模型厂商以自研模型为核心的 API 服务不同，「Runway Dev」同样走“聚合”路线，接入了 Seedance、Google Omni Flash 等多个视频模型。

更值得关注的是“模型路由”机制，是「Runway Dev」的最大卖点。举个例子来理解，开发者为某个创作场景创建“路由”、设定模型偏好（在成本、速度、质量之间排优先级）、选择候选模型，以及单次生成的价格上限。

实际使用中，每次请求都会带上对应的“路由 ID”，系统会先做一轮硬性筛选，把能力不符、不在候选名单内、以及会超出价格上限的模型全部排除；如果没有任何模型符合条件，会直接报错，并指出原因。通过筛选后，系统再从剩下的模型中按用户设定的偏好打分，选出得分最高的模型开始执行，并在结果中注明调用模型、原因和费用。

在文字领域，OpenRouter 早已提供类似，从机制上看，「Runway」的模型路由并不新鲜。但在视频领域，由于生成成本高、评价维度复杂，只有面向某些特定场景的产品可以依据具体任务流程去打磨、做内部的自动路由来打出低成本高效的“标签”吸引用户，而 API 层面做自动路由，却很少见。按「Runway」首席产品官 Anthony Maggio 的说法，公司内部创意团队对各模型在运动、构图、口型同步等维度做了专项评估，以此驱动路由选择，但具体标准并未公开。

此外，「Runway Dev」还提供串联多步生成的 Workflows、将广告生成等常见营销场景封装成一次调用的 Recipes，以及供 AI 助手和编程智能体调用「Runway」的 MCP 服务。

创作工具和 API 两个层面，「Runway」的卖点都已经不再是模型，而是在聚合的基础上再做差异化。而 API 解决了调用的灵活性，对另一类客户来说仍然不够，拥有大量专有 IP、具备自有算力、对数据安全有严格要求的大型企业，需要的是把模型拿到自己的环境里私有部署。

基于此，Gen-4.5 虽然能力不再领先，但依然能赚一些钱，第三层，模型授权。

在这一层，「Runway」依然走了一条不一样的道路。「Runway」与一些公司或组织达成授权协议，将自研的闭源模型（比如 Gen-4.5）授权给企业使用，企业可以自行部署、利用自己的数据进行微调，产生的商业收入归企业所有，「Runway」只收取授权费用。

这条路位于闭源和纯开源之间。「Kling」「Seedance」等闭源模型只能通过 API 调用，不支持私有部署；纯开源模型的权重虽然开放，但适配、调优、部署和后续维护的成本全部由企业承担。「Runway」的做法是将模型权重完全交到企业手中，同时附带多版本 Checkpoint 和训练脚本，并派技术人员协助微调与维护。企业买到的，某种程度上是一套“省心部署”方案：既有私有部署的安全感，又不用从零折腾开源基座。

图片来源：「Runway」Model Licensing 官网

创始人在领英帖文上表示，“目前「Runway」最大的客户越来越多开始直接授权「Runway」的前沿模型。”不过，企业买到的这套“省心部署”，底层仍是 Gen-4.5 这个已经在榜单上不算“顶尖”的基座，省心之后的效果如何，可能还要看微调环节能做到什么程度。

写在最后

把三层放在一起看，「Runway」的逻辑清晰，形成一个漏斗，用户不同，交付方式也随之变化。支撑这个漏斗的不是“模型强”，而是把同一套架构能力包装成不同形态，匹配到每一层客户愿意买单的交付方式上。

「Runway」的选择是退出 AI 视频的军备竞赛，在商业化路径上做出差异。

不过，当模型能力不再是护城河时，“包装”本身能不能成为护城河，仍有待验证。创始人 Germanidis 在多个场合强调，「Runway」是一家“世界模型公司”，视频生成不是终点，而是理解物理世界的一条路径，世界模型会建立对环境的内部表征，支持实时交互，预测某个动作执行后会发生什么，用于机器人、自动驾驶和科学研究。但在那个未来到来之前，「Runway」或许需要通过商业层的差异化拿到更多用户反馈，回到模型能力的第一梯队。
